# 2026-09-22 Origin Note

## Background

During `local-ai-connector` cleanup, the distinction between owner Mac and spouse Windows was clarified:

- spouse Windows uses `Office` / `Paper` separation.
- owner Mac does **not** use paper/research workflows.
- A mistaken Mac application of spouse Office/Paper instructions showed that policy needs to be tracked separately from individual tool repos.

## User Direction

The user suggested that trends keep changing, so a separate mechanism is needed to reflect current model and harness trends and adjust standing instructions over time.

Important points from the conversation:

- This should be separate from `tierwork`.
- This should also be separate from `local-ai-connector`.
- The scope is not only model trends, but also harness behavior.
- Relevant harnesses include Claude Code, Codex, Pi, Telegram bridge, MCP, and skills/tools.
- Each service does optimize its own model/harness, but not this user's multi-repo, multi-harness, project-specific standing instructions.
- The goal is lightweight operational policy hygiene, not a large benchmark project.

## Chosen Name

`agent-policy-radar`

Description:

> Tracks model and harness changes, reviews standing agent instructions, and proposes project-specific prompt/policy updates.

## Working Model

1. Collect service-provided documentation and capabilities.
2. Record model/harness observations with dates.
3. Compare those observations against local standing instructions.
4. Propose changes per project.
5. Apply changes only after explicit approval in the target project.

## Candidate Tooling Mentioned

These tools may help with parts of the workflow, but none fully replaces project-specific policy review:

- promptfoo: prompt/model comparison and regression tests.
- Langfuse: LLM observability and traces; self-hostable.
- Braintrust: eval/dataset/experiment management.
- Helicone: API gateway, logging, cost/performance observation.
- Arize Phoenix: open-source observability/eval.
- W&B Weave: LLM trace/eval experiment management.
- Humanloop, PromptLayer, Parea AI, Agenta, Portkey: prompt registry and operations tools.

For this project, the default is notes + proposals first. Tooling can be added later if it earns its keep.

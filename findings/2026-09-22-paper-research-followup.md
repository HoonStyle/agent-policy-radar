# Paper Research 후속 검증 시도 — 2026-09-22

## 목적과 변경

앞선 가상 사례에서 발견한 불필요한 통계 추론 및 코드 미공개=재현 불가 혼동을 보완한다. 참고 문서뿐 아니라 공통 SKILL.md에도 이 두 경계를 짧게 명시했다. 연구 전체에 새 절차나 필수 기록을 추가하지 않았다.

## 실행 기록

입력은 공개 배포 skill/관련 참고 문서와 두 가상 질문만 의도적으로 제공했다. 실제 비공개 논문이나 데이터는 제공하지 않았다. 도구는 비활성화했다.

1. Claude `--bare` + custom system prompt 시도: `Not logged in` 실패. 모델 호출 사용량 0, 비용 0, duration 62ms. 기존 키체인 인증을 읽지 않는 모드이므로 실제 검증이 수행되지 않음.
2. bare 없이 동일 명시 system prompt + `--max-budget-usd 1`로 시도: exit 1, is_error=true, result=null. duration 18,444ms. CLI list-price 추정 비용 $3.26568. modelUsage에는 claude-fable-5-1, input 2, cache creation 160,983, output 920 tokens로 보고됐으나 상위 usage는 0으로 상충. 청구액이 아니라 CLI 추정치이며 결과 텍스트는 반환되지 않음.

## 판단

- 예산 옵션이 단일 요청 비용의 사전 hard cap으로 작동했다고 볼 수 없음. 설정 예산 초과를 확인하고 추가 호출 중단.
- 명시 system prompt만으로 개인/하네스 컨텍스트가 격리됐다고 주장할 수 없음. 예상 밖 컨텍스트 크기의 원인은 아직 분석하지 않음.
- 이번 시도로 보완 후 행동 통과를 주장하지 않음. 인증/컨텍스트/비용 제어가 확인된 실행 경로에서 재검증해야 함.
- 최소 모드 실패는 모델 출력이 없음을 확인한 후 경로를 변경했고, 예산 초과 후 결과 불명 호출을 다시 실행하지 않았음.
- 실제 논문 대조, Codex 행동 검증은 여전히 미실행. 이번 작업은 국소 지침 보완 및 실패 기록까지 완료.

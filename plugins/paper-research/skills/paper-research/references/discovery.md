# 탐색·비교

## 탐색

1. 연구 질문과 포함/제외 기준을 요청 규모에 맞게 정한다. 분야·기간·언어·연구 유형을 명시하되 불필요한 제한을 만들지 않는다.
2. 사용 가능한 공식 학술 검색/출판사/학회/저장소를 사용한다. 핵심 용어·동의어·반례/비판 용어를 탐색하고 중요한 논문의 참고문헌/후속 인용을 필요 범위에서 확인한다.
3. 확인한 제목·저자·연도·식별자·버전을 기록하고 동일 연구의 preprint/출판본을 중복 실적으로 세지 않는다. 자동으로 다른 버전의 결과를 합치지 않는다.
4. 요청 규모에 맞게 필요한 범위에서 검색 날짜·쿼리·사용 출처·접근 제한·선정 이유를 남긴다. 간단한 탐색은 응답 내 짧은 설명으로 충분하며 별도 기록 파일을 요구하지 않는다. 소규모 탐색을 체계적 문헌고찰이나 완전한 최신 동향 조사라고 부르지 않는다.
5. systematic review가 명시적으로 요청되면 프로토콜·선별·배제 이유·중복 제거·편향 평가를 계획하고 실제 수행 수준을 보고한다. PRISMA 등 특정 기준 준수를 수행 없이 주장하지 않는다.

검색 도구가 없으면 사용자 제공 문헌으로 범위를 좁히거나 검색 전략만 제안한다. 검색을 실행했다고 꾸미지 않는다.

## 비교

필요한 열만 사용한다:
- 연구 질문 / 기여 / 선행 방법과의 차이
- 방법·가정 / 모집단 또는 데이터 / 실험 설계
- 비교 대상 / 평가 지표 / split·누수 가능성 / 비용·표본 크기
- 보고 결과와 근거 위치 / 불확실성 / 한계
- 원문 접근 수준 / 공개 코드·데이터 여부

정량 순위는 비교 조건이 타당할 때만 제시한다. 논문 자체의 주장을 독립적인 성능 보증으로 바꾸지 않는다. 서로 다른 분야의 연구를 모두 ML 벤치마크 표에 맞추지 않는다. 이론 연구는 정의·가정·증명 범위를, 질적 연구는 표집·분석 과정·반성성·전이 가능성을 검토한다.

# 간호학 통계·결과 집필 — 선택 참고

분석법을 이름만으로 고르지 않는다. 질문/추정대상, 설계, 변수 척도·분포, 표본 수, 반복/군집 구조, 결측과 주요 가정을 먼저 확인한다. 복잡한 분석은 지도교수·통계 전문가 검토가 필요할 수 있다. 도구 실행 성공은 분석 타당성의 증명이 아니다.

## 분석 선택과 진단

- 기술통계는 변수 특성과 설계에 맞는 분모·분포 요약을 제공한다. 범주 값의 평균이나 표본의 독립성을 무심코 가정하지 않는다.
- 집단 차이·연관성 분석은 독립/대응·반복/군집 구조, 분포, 분산, 잔차 등 해당 방법의 가정을 확인한다. 정규성 검정 p값 하나로 모든 방법을 자동 결정하지 않는다.
- 회귀는 결과변수 유형(연속/이항/계수/생존 등), 교란 구조, 비선형성·상호작용·다중공선성·희소 사건·과적합을 검토한다. 단변량 p값만으로 교란변수를 고르거나 자동 stepwise를 기본으로 삼지 않는다.
- 반복 측정·종단·군집 연구는 mixed model, GEE 등 질문에 적합한 접근과 추정대상을 검토한다. 군집 배정 자료를 독립 개인 표본처럼 분석하지 않는다.
- 매개/조절·SEM/CFA는 이론적 근거·시간 순서·식별·추정법·측정척도·모형 적합과 대안 설명을 검토한다. fit cutoff 하나 또는 유의한 간접효과만으로 모형/인과 타당성을 확정하지 않는다. 수정지수로 모형을 바꾼 경우 사후 변경을 명시한다.
- 척도 분석은 신뢰도와 타당도를 구분한다. EFA/CFA·불변성 등의 필요성과 동일 표본 탐색/확증에 따른 한계를 확인한다. 필요한 표본 수를 고정 비율로 보장하지 않는다.
- 주요/부차/탐색 결과, 다중 비교, 민감도 분석을 구분한다. 통계적 유의성과 임상적 중요성을 분리하고 효과크기·신뢰구간을 함께 해석한다. 비유의 결과는 효과 없음의 증명이 아니다.

## SPSS · AMOS · R

사용자가 선택한 도구와 보유 버전을 우선한다. 설치·라이선스·모듈·파일 접근 여부를 먼저 확인하며 구매나 우회 설치를 하지 않는다.

- SPSS: 값 라벨/사용자 결측/가중/필터/split file 상태와 사용한 syntax, 출력 표를 확인한다. 메뉴를 실제로 조작하지 않았다면 실행했다고 하지 않는다. .sav를 다른 도구로 읽을 때 메타데이터·결측 처리 변화를 확인한다.
- AMOS: 모형/경로 제약·추정법·입력 행렬/원자료·결측 처리·bootstrap 설정과 실제 출력 경고를 확인한다. 경로도만 보고 적합도나 유의성을 만들어내지 않는다.
- R: 승인된 패키지·버전·seed·분석 script와 실제 출력 결과를 남긴다. 패키지 설치·네트워크·장시간 계산은 기존 실행 권한을 따른다.

여러 도구를 모두 돌리는 것을 의무화하지 않는다. 교차 검증이 필요할 때만 같은 표본·결측·추정법·기준범주·가중 설정을 맞춰 비교한다. 소프트웨어 간 차이를 바로 버그로 단정하지 않는다. 실행 환경이 없으면 syntax/분석 계획 초안과 미실행 상태를 제공한다.

## 분석 → 표·그림 → 문장

가능하면 승인된 동일 분석 출력에서 표·그림·본문 수치를 만든다. 표마다 분석 표본/분모·시점·단위·추정치·불확실성·검정법을 확인한다. 반올림, 기준집단, 부호 방향, CI·p값, 누락 자료와 다중 비교 처리를 대조한다. p값을 임의로 0이라고 쓰거나 유의성 표시만으로 결과를 대체하지 않는다.

결과 절에는 관측 결과를, 논의에는 해석·대안 설명·한계를 구분해 작성한다. 척도 범위와 임상적 의미를 고려하고 통계적 차이만으로 환자 치료 권고를 확정하지 않는다. 검토한 실제 출력이 없으면 수치 칸을 비우거나 미확인으로 표시한다. 연구 결과를 만들거나 원래 분석과 다른 수치를 글에 맞춰 수정하지 않는다.

## 검증 범위

이 문서는 방법 선택과 점검을 돕는 절차다. 특정 데이터셋의 분석 정답, IRB 적합성 또는 SPSS/AMOS/R 실제 실행을 보증하지 않는다. 해당 연구에서 수행한 분석·검증과 하지 않은 작업을 구분해 보고한다.
